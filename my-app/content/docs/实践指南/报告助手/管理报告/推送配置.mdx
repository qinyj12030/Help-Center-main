# 推送配置

智跃Zleap支持将生成的报告自动推送到多个平台，让团队成员及时获取报告内容。

## 支持的推送方式

### 1. 企业微信机器人

通过企业微信群机器人推送报告到指定群聊。

**配置步骤：**
1. 在企业微信群中添加机器人
2. 获取机器人 Webhook 地址
3. 在报告推送配置中填入 Webhook 地址
4. 设置推送时间和频率

### 2. 飞书机器人

通过飞书群机器人推送报告到指定群聊。

**配置步骤：**
1. 在飞书群中添加机器人
2. 获取机器人 Webhook 地址
3. 在报告推送配置中填入 Webhook 地址
4. 设置推送时间和频率

### 3. 钉钉机器人

通过钉钉群机器人推送报告到指定群聊。

**配置步骤：**
1. 在钉钉群中添加机器人
2. 获取机器人 Webhook 地址
3. 在报告推送配置中填入 Webhook 地址
4. 设置推送时间和频率

### 4. 邮件推送

通过邮件方式推送报告。

**配置步骤：**
1. 设置收件人邮箱地址
2. 选择推送频率（每日、每周、每月）
3. 设置推送时间
4. 选择报告格式（HTML、PDF）

## 推送设置

### 推送频率

- **实时推送** - 报告生成后立即推送
- **定时推送** - 每日/每周/每月的固定时间推送
- **手动推送** - 仅在手动触发时推送

### 推送内容

可以选择推送的内容类型：
- 完整报告
- 报告摘要
- 仅推送链接

## 注意事项

- 确保 Webhook 地址的安全性，不要泄露给无关人员
- 推送频率不宜过高，避免打扰团队成员
- 定期检查推送日志，确保推送正常运行
