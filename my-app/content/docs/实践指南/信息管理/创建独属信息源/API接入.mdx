# 通过API接入创建信息源

智跃Zleap提供API接口，允许您通过编程方式将数据接入系统。

## 适用场景

- 自动化数据同步
- 与现有系统集成
- 批量数据导入
- 实时数据推送

## 配置步骤

### 1. 获取API密钥

在系统设置中生成API密钥，用于身份验证。

### 2. 创建信息源

通过API创建信息源，指定数据格式和同步方式。

### 3. 推送数据

使用API接口将数据推送到信息源。
