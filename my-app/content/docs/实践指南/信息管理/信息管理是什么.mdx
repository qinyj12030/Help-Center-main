## 事件表格

### 什么是事件表格？

事件表格是 SAG（SQL驱动的RAG引擎） 将非结构化数据（如文档、聊天记录）通过 AI 预处理后，转化而成的结构化数据库（关系型的表单数据），后续SAG可以根据此数据库构建事件之间的联系。

<div className="my-6 space-y-3">
  <div className="border-l-4 border-primary pl-4">
    <strong>语义原子事件：</strong>不是将上下文按字符机械切块，而是将信息拆解为语义完整、彼此独立的"事件"作为记录。
  </div>
  <div className="border-l-4 border-primary pl-4">
    <strong>自然语言向量（多维属性）：</strong>它为每个事件抽取多个维度的属性作为列（打标签），形成"多维表格"。默认维度包括 5W1H（时间、地点、人物、话题、行为、标签），并且支持根据具体业务场景自定义扩展维度（如风险等级、项目阶段等）。
  </div>
</div>

### 事件表格在算法层面的作用

事件表格是 SAG 算法实现"快、准、全"的技术基石。以事件表格为关键组件的SAG能实现更精准的结构化推理，而不只是单纯的向量匹配。

- **"先结构化，再检索"的新范式** — 传统 RAG 依赖向量空间的模糊匹配，容易产生幻觉。事件表格通过将数据 SQL 化，让系统能够利用 SQL 的精准检索能力进行毫秒级的确定性查询。
- **查询时动态构图** — SAG 不需要预先维护庞大且僵化的知识图谱。它利用事件表格中存储的共同实体（属性），在查询瞬间通过 SQL 快速寻找不同事件间的联系，解决了增量数据进入时需要重新绘制图谱的问题。
- **驯化向量的不确定性** — 利用向量检索来处理自然语言的模糊性，关联到具体的属性 ID，从而切换到事件表格进行精准的 SQL 关联与多跳扩展（BFS）。
- **PageRank 智能排序** — 在检索出的子图上，算法基于事件表格中的实体权重、频次和时间维度运行加权 PageRank，从而实现比传统语义相似度更精准的 Rerank 排序。

### 事件表格在数据聚合与查询方面的优势

事件表格可以将海量数据转化为可查询、可计算、可追溯数据资产。对使用者而言，事件表格具有以下优势：

- **直达真相与完整溯源** — 您得到的不会是 AI 凭空捏造文字，而是基于表格中结构化数据组合而成的答案。表格中的每一条信息都关联原始数据层，确保结果 100% 可溯源，消除AI"幻觉"问题。
- **复杂的聚合与对比查询** — 基于事件表格，AI 可以直接利用 Text-to-SQL 能力进行统计和对比分析，从而回答"上周有多少客户投诉""对比 A 项目和 B 项目的风险"等复杂问题。
- **根据业务逻辑灵活扩展** — 用户可以根据行业需求（如医疗、项目管理）自定义表格维度。这意味着用户可以教 AI 按照业务特有的逻辑（如"诊断"或"优先级"）去观察和关联公司的数据。
- **激活沉睡的数据资产** — 将零散的聊天记录、笔记、文档、网页聚合为结构化知识库。对于 CEO 而言，这就像拥有了一个"今日头条"式的真相报告系统，能够穿透层层过滤，直接看到由底层事件表格支撑的真实业务动态。
